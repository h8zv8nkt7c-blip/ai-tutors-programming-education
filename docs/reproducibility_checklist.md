# Two-minute reproducibility and audit checklist

- [ ] The README states the research question, hypotheses, study status, primary outcome, and limitations.
- [ ] A reviewer can build the pinned container and run the sample analysis using the documented commands.
- [ ] Data columns, score ranges, group labels, analysis configuration, and synthetic-vs-real data status are clear.
- [ ] The protocol records assignment, controlled conditions, model/version, rubric, follow-up timing, analysis plan, and validity risks.
- [ ] The repository excludes credentials, participant identifiers, raw private data, generated results, and large binaries; license and citation information are present.
