# Карточка методологии исследования

## Информация о проекте

- **Название:** AI Tutors in Programming Education: Do Hints Help Students Retain What They Learn After the Session?
- **Авторы:** Aruzhan Akmurzayeva; Adel Baimukhambetova
- **Публичный GitHub-репозиторий:** https://github.com/h8zv8nkt7c-blip/ai-tutors-programming-education
- **Исследовательский вопрос:** Отличается ли результат самостоятельного теста переноса знаний по Python через семь дней в зависимости от стиля помощи ИИ: последовательные обучающие подсказки, чат-бот без ограничений или обучение без ИИ?

## Тип исследования

**Количественное исследование, рандомизированный эксперимент с тремя группами.** Участники изучают одинаковые темы и выполняют сопоставимые задания при одинаковом ограничении времени. После короткой диагностики начальных знаний их распределяют между тремя условиями, желательно со стратификацией по исходному уровню. Непосредственный результат измеряется во время практики; через семь дней участники самостоятельно решают новую задачу переноса без ИИ. Количественные оценки позволяют сравнить результаты между условиями и учесть исходный уровень.

## Гипотезы

### Основной вопрос: отсроченный перенос знаний

- **H₀₁:** Средний балл самостоятельного теста переноса через семь дней одинаков в группах обучающих подсказок, неограниченного чат-бота и контроля без ИИ: μₕ = μᵤ = μ꜀.
- **H₁₁:** Средний балл отсроченного теста в группе последовательных обучающих подсказок выше, чем в группе неограниченного чат-бота и контрольной группе: μₕ > μᵤ и μₕ > μ꜀.

### Немедленное выполнение и сохранение знаний

- **H₀₂:** Разница между непосредственным баллом практики и отсроченным независимым баллом не различается между условиями.
- **H₁₂:** Группа неограниченного чат-бота показывает более высокий балл во время практики, но больший спад к независимому тесту, чем группа обучающих подсказок.

### Модерация исходными знаниями

- **H₀₃:** Исходный уровень знаний Python не меняет связь между условием помощи и отсроченным результатом.
- **H₁₃:** Преимущество последовательных подсказок по отсроченному переносу сильнее у участников с более низким исходным уровнем знаний.

## Метрики и baseline

- **Первичная метрика:** средний балл самостоятельного теста переноса через 7 дней (0–100 по общей рубрике). Главный анализ сравнивает три группы с учетом исходного диагностического балла.
- **Пороговые метрики (guardrails):** доля отсутствующих отсроченных результатов и доля нарушений протокола по каждой группе; оба показателя показываются рядом с результатами, чтобы потери участников не скрывали смещение. Также проверяется диапазон баллов и отсутствие идентификаторов.
- **Вторичные метрики:** непосредственный практический балл; разница «практика минус отсроченный тест»; типы ошибок и качество независимого решения по рубрике.
- **Baseline / контрольная группа:** обучение без ИИ. Для причинного сравнения группы распределяются случайно, сбалансированно по исходным знаниям. Сравнение AI-групп проводится на одинаковых заданиях и сроках; контрольная группа не получает доступа к ИИ во время практики.
- **План анализа:** сначала описательные статистики, размеры групп, пропуски и соблюдение протокола. Для первичного исхода — модель отсроченного балла с условием и исходным баллом; заранее запланированные сравнения «подсказки против неограниченного чата» и «подсказки против контроля» с поправкой на множественные сравнения. Для H₀₂ анализируется разница баллов между моментами, для H₀₃ — взаимодействие исходного балла с условием. Уровень значимости и обработку пропусков следует зафиксировать до анализа данных.

## Воспроизводимость и этика

Использовать одинаковые учебные материалы, ограничения времени, модель и инструкции для групп ИИ; документировать версию модели, платформу, ОС и процедуру оценивания. Оценивать решения по одной рубрике; по возможности скрыть условие участника от проверяющих. Участие добровольное, оценки эксперимента не влияют на итоговую отметку курса. В репозитории хранить только обезличенные данные; приложенный CSV — синтетический пример для проверки пайплайна, а не реальные результаты.

## Формулы и заранее заданный анализ

Пусть `Yᵢ` — балл переноса участника `i` через 7 дней, `Pᵢ` — балл практики, `Bᵢ` — начальный балл, `Gᵢ` — группа. Основная модель: `Yᵢ = β₀ + β₁Gᵢ + β₂Bᵢ + εᵢ`, где `Gᵢ` кодируется индикаторами. Главные контрасты: скорректированное среднее подсказок минус среднее чат-бота и скорректированное среднее подсказок минус контроль без ИИ; сообщить 95% доверительные интервалы, а p-значения контрастов скорректировать методом Holm. Для H₀₂ анализировать `Dᵢ = Pᵢ − Yᵢ`. Для H₀₃ добавить взаимодействие условия с `Bᵢ`. До сбора данных определить расчёт размера выборки, порог значимости, правила исключения, обработку пропусков и анализ чувствительности.

## Ограничения текущего репозитория

Локальный анализатор проверяет схему и диапазоны данных, считает описательные статистики и нескорректированные разницы средних. Он не выполняет регрессионный анализ, тесты гипотез, поправку Holm или анализ пропусков. Файл `data/sample/sample.csv` содержит только синтетические строки; публиковать его как результаты исследования нельзя. Полный протокол дизайна, метрик, baseline, валидности и приватности находится в `docs/experimental_protocol.md`; короткий аудит готовности — в `docs/reproducibility_checklist.md`.
